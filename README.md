# Default Wallpaper Restore

A simple Windows utility developed by **Bytetastic App Productions** to restore the default Windows wallpaper.

## Download

**[Download the latest version](YOUR-GITHUB-RELEASES-LINK)**

1. Open the latest GitHub Release.
2. Scroll down to the **Assets** section.
3. Download `Default Wallpaper Restore.exe`.
4. Open the downloaded application.

> Always download the application from the official GitHub repository.

## Features

- **Default Wallpaper Restore** – Sets the Windows desktop wallpaper to the default Windows wallpaper.
- **Built-in Wallpaper Access** – Uses the default wallpaper stored in the Windows system directory.
- **Registry Configuration** – Updates the current user's Windows wallpaper registry settings.
- **Wallpaper Style Configuration** – Sets the wallpaper style to Fill.
- **Instant Desktop Refresh** – Refreshes the desktop wallpaper without requiring a restart.
- **Welcome Message** – Displays an introduction before applying the wallpaper.

## How to Use

1. Launch `Default Wallpaper Restore.exe`.
2. Read the welcome message.
3. The application accesses the built-in Windows wallpaper.
4. It updates the wallpaper configuration.
5. Your desktop wallpaper is refreshed automatically.

## Wallpaper Information

The application uses the following built-in Windows wallpaper:

`C:\Windows\Web\Wallpaper\Windows\img0.jpg`

The wallpaper style is configured to **Fill**.

## Requirements

- Windows operating system.
- Access to the built-in Windows wallpaper directory.
- Permission to update the current user's wallpaper registry settings.
- Windows Script Host and PowerShell.

## Important Information

- The application changes the desktop wallpaper for the current Windows user.
- It modifies wallpaper-related registry settings.
- The default wallpaper image must exist in the expected Windows directory.
- The application is designed to restore the standard Windows wallpaper, not download a new wallpaper.
